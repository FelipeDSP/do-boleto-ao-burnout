# Do Boleto ao Burnout

Landing page de captura de leads + revista digital da estud.you.

- index.html: landing page com formulario (nome, WhatsApp, e-mail)
- revista.html: a revista, liberada apos o cadastro

Os leads sao gravados numa planilha do Google Sheets via Apps Script.
Deploy estatico via Coolify em live.estudyou.com
